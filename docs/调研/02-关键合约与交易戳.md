### PoolManager 事件（监听二级盘的主过滤器）

| 事件 | topic0 | 用途 |

| `Swap(bytes32,address,int128,int128,uint160,uint128,int24,uint24)` | `0x40e9cecb9f5f1f1c5b9c97dec2917b7ee92e57ba5563708daca94dd84ad7112f` | 买卖；样本 1 已解码。indexed：`id`(poolId)、`sender`(通常是 Router) |

**解析注意：** v4 `Swap` **没有 token 地址**。必须用 `Initialize` 或发射台事件建立 `poolId → (currency0, currency1, fee, tickSpacing, hooks)`。`amount0`/`amount1` 为 `int128`，文档口径为负号表示池子付出该侧（实现时以 meme `Transfer` 方向交叉；见监听探测）。同笔 `Swap` 的 `sqrtPriceX96` 是成交后中间价（公式见下）。**成交单价**用 Transfer 净额比。写 `launch_index` 的节奏见需求 `01` §3.8（有成交才刷、默认 3 秒、单位 U），不要每笔 Swap 打 SQLite。

### v4 实时价（o1 / Long / Pons 毕业盘共用）

Uniswap v4 与 v3 相同：`sqrtPriceX96` 表示 **currency1 / currency0** 的平方根价，按最小单位。

```text
Q96  = 2^96
raw  = (sqrtPriceX96 / Q96)^2          # 1 个 currency0（wei）换多少 currency1（wei）

# 1 枚 meme（1 * 10^tokenDec）值多少 quote（人类单位）：
若 meme == currency0 且 quote == currency1：
    spot_quote = raw * 10^(quoteDec - tokenDec)
若 meme == currency1 且 quote == currency0：
    spot_quote = (1 / raw) * 10^(quoteDec - tokenDec)

spot_usd = spot_quote * usd_per_1_quote
```

成交价（exec）不用 sqrt，用本笔 `|Δquote| / |Δmeme|` 再按 decimals 缩放。谁是 meme / quote 以创建时记下的 `currency0/1` 为准，**不要假设 meme 永远是 token1**。

`usd_per_1_quote`：USDG≈1；ETH/WETH 用 eth_usd；股票代币用该股 USD。缺失则只写 `spot_quote`。协议细节见 `06`（曲线）/`07`（o1）/`09`（Long）。

ERC-20 `Transfer` 仍是 `0xddf252ad1be2c89b69c2b068fc378daa952ba7f163c4a11628f55a4df523b3ef`，可作成交确认，不能单独当「这是 meme 买」。

### Universal Router 交易戳（二级买入主路径）

| 项 | 值 |
| --- | --- |
| selector | `0x3593564c` |
| 签名 | `execute(bytes commands, bytes[] inputs, uint256 deadline)` |
| v4 单跳 command | `0x10` = `V4_SWAP` |
| 常见 actions | `0x06` `SWAP_EXACT_IN_SINGLE`，`0x0c` `SETTLE_ALL`，`0x0f` `TAKE_ALL` |
| Robinhood 特有 | `SwapExactInSingle` **多一个** `uint256 minHopPriceX36`，官方/Bags 要求填 `0`。用原版 Uniswap SDK 编码会 revert |

```text
struct SwapExactInSingle {
    PoolKey poolKey;        // currency0, currency1, fee, tickSpacing, hooks
    bool zeroForOne;
    uint128 amountIn;
    uint128 amountOutMinimum;
    uint256 minHopPriceX36; // 本链必填，恒为 0
    bytes hookData;         // 通常 0x
}
```

Bags 文档还写：本链有其它长得像 Router 的合约，**只有** `0x8876…0904` 是这条 fork。
