官方明确：公开 RPC 有限流，**不建议生产**。2026-09-02 复测结果：

- 官方 `https://rpc.mainnet.chain.robinhood.com` 带产品 User-Agent 时，`eth_chainId=0x1237`、`eth_blockNumber`、`eth_getBlockReceipts` 均成功。
- 使用 8 路有界预取连续扫块时，官方公网节点会返回 HTTP `429`；真实服务能解析 Pons 新盘和 ETH 曲线价格，但无法长期追平约 100ms 的出块速度。
- NodeFlare 公网端点能返回 chainId 与整块收据，但连续启动测试同样遇到 `429`。
- Blockmachine 公网端点实测支持 `debug_traceTransaction(callTracer)`，本期仅作为原生 ETH 净额的可选 trace RPC，证据与严格降级见 `11-v4原生ETH成交净额.md`。

结论：仓库 `.env` 的官方 RPC 只用于本地功能验收。持续运行必须换成自有或供应商专用端点；密钥只放 `.env`，不得进入仓库。

## 浏览器口径

- **官方**：`robinhoodchain.blockscout.com`。两笔样本交易的 calldata / logs / token 均从此处 API 取到。
- **用户链接**：`rh-scan.com` 是 Etherscan 风格第三方浏览器，能打开第一笔（Universal Router 换 LKDOG），第二笔被 Cloudflare 拦截。地址标签可用，但索引与 API 不稳定，**实现不要依赖它**。
- GMGN：`https://gmgn.ai/?chain=robinhood` 是终端，不是链。GMGN 把 Robinhood 发射台标成 `trench` / `pons` 等，链上仍是下面文档里的工厂合约。

## 和 BSC Fourmeme 运行环境对比

| | `go_fourmeme_v3`（BSC） | Robinhood Chain |
| --- | --- | --- |
| Chain ID | 56 | 4663 |
| 块时间 | ~3s | 约 100ms（Bags 文档；待用自有节点复核） |
| 排序 | 普通 gas 竞价 | **FCFS，优先费买不到排序** |
| 监听 | `eth_getBlockReceipts` 轮询 | 同样可行（需在自有 RPC 上验证该方法） |
| 交易发送 | `eth_sendRawTransaction` | 同左；也可走 sequencer URL |
| 内盘 | 单一 TokenManager | 多发射台曲线 + 大量直接 v4 池 |

**建议 / 推断：** 把 Fourmeme 的 3 秒 ticker 原样搬过来会漏块。v1 应改为「追最新块号、按区间拉 receipts」，或订阅 `newHeads` / sequencer feed。FCFS 意味着跟单拼的是 **看到事件到签名广播的延迟**，不是 gas。
