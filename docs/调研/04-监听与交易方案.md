# 04 监听与交易方案（对照 go_fourmeme_v3）

- 最新更新时间：2026-09-01 17:50 (UTC+8)
- 适用范围：后续实现边界；本文件不写代码
- 来源：本地 Fourmeme parser/trader、本文 01–03、Bags Trade Tokens 指南

## 1. Fourmeme 现在怎么跑

本地路径（只作对照）：

- 轮询：`internal/core/parser/block_parser.go` → `eth_getBlockReceipts`
- 分流：`handlerV2.go` → Create / Buy / Sell
- 买事件：Manager1/2 固定 topic，data 里直接有 token、buyer、amount
- 下单：`BuyTokenViaManagerV2` → `TokenManager2.buyTokenAMAP`，`to` 固定 Manager，`value=BNB`

这套成立的前提是：**全市场买卖都打在 2～3 个固定地址上**。

## 2. Robinhood 能不能套同一骨架

**骨架能套，领域层必须拆 adapter。**

```text
[块轮询 / newHeads]
        ↓
 eth_getBlockReceipts（待自有 RPC 验证）
        ↓
 按 log.address + topic0 分流
        ├── PoolManager.Initialize / Swap     → 二级盘
        ├── Pons TokenLaunched / CurveBuy     → 新盘内盘（Debot 1h 卡）
        ├── Long LaunchCreated / PoolManager.Swap（poolId ∈ launch_long）
        ├── o1 factory Launched / Hook.Trade  → 股票/加密配对金狗
        ├── pools.trade TokenCreated          → 新币（无内盘）
        ├── Bags TokenCreated / TokensBought  → 内盘
        └── hood.fun TokenCreated / Trade     → 内盘（毕业走 v3）
        ↓
 策略（聪明钱 / 新开盘 / 白名单 creator）
        ↓
 Trader
        ├── 未毕业：曲线 buy（Bags/Pons/hood）
        └── 已开 v4：UniversalRouter.execute
```

| Fourmeme 模块 | Robinhood 对应 | 能否直接搬 |
| --- | --- | --- |
| `StartBlockPolling` | 同模式，间隔要按 100ms 块改 | 半套：逻辑可搬，参数不行 |
| `DefaultMonitorTargets.FourmemeManagers` | PoolManager + 多个工厂 | 否，要列表化 |
| `FourmemeTopics` Buy/Sell | 按协议多组 topic | 否 |
| `getTokenInfo` Helper | BagsLens / 各 `curves()` / StateView | 否 |
| `buyTokenAMAP` | 见下节 | 否 |
| 聪明钱跟买 | 仍可用：从 Swap/Transfer 取 buyer | 策略可搬，解析要改 |
| 私钥签名发送 | EIP-155 chainId=4663 | 是 |

## 3. 如何解析（落地顺序）

### 阶段 A — 只做 v4 二级盘（覆盖样本 1，部分覆盖样本 2）

1. 监听 `PoolManager` 的 `Initialize`：记下 poolId、currency0/1、fee、tickSpacing、hooks。
2. 监听 `Swap`：用 poolId 反查 token；`amount0/1` 符号判断方向。
3. 用户地址：`tx.from`，或 meme `Transfer` 的 `to`（不要用 Swap.sender，那是 Router）。
4. 用 hooks 粗分协议：`0x0` ≈ pools.trade；Pons hook；Bags hook；其它后标。

### 阶段 B — 新币发现

并行听工厂，不要从「全链 Transfer mint」扫（噪音极大）：

- Pons factory `TokenLaunched`（带出 curve、pairToken）— Debot 新盘
- LongLauncher `LaunchCreated`（带出 asset、numeraire、launcher）— Debot `long`；同笔 `Initialize` 记 poolId
- o1 股票工厂 `Launched`（带出 token、poolId、quote）— Debot 金狗
- 可选：o1 加密工厂、pools.trade 两个 entry 的 `TokenCreated`
- Bags factory `TokenCreated`（带出 curve、poolId）
- **不要**用 Airlock `Create` 当 Long 发现源（Bankr 等共用）

### 阶段 C — 内盘成交

- Pons：全链 `CurveBuy` topic（emitter 是各曲线）；用户取 `recipient`
- Long：`PoolManager.Swap` 且 poolId 已在 `launch_long`；不要用 DopplerHookInitializer 单例当过滤器；用户取 token `Transfer`
- o1：`PoolManager.Swap` 且 hooks=LaunchHook；同 tx 的 Hook `Trade` 只读费用；用户取 token `Transfer`
- Bags：各曲线 `TokensBought`（或先缓存 curve 集合再过滤地址）
- hood.fun：launchpad 上 `Trade`

## 4. 如何交易

### 4.1 已开 v4 池（主路径，对齐样本 1）

1. `StateView.getSlot0(poolId)` 确认池活着。
2. `V4Quoter.quoteExactInputSingle` 必须 `eth_call`/`simulate`，它不是 view。
3. 编码 UR `execute`，**带上 `minHopPriceX36=0`**。
4. 买 ETH 计价池：`value=amountIn`，command `0x10`。
5. Bags 毕业池是 token/WETH：可能要先 `WETH.deposit`，再 Permit2 授权 UR。Bags 文档：只做 exact-in；exact-out WETH 会被 hook revert。
6. deadline 用 **时间戳** 不是块号（官方/Bags：100ms 块）。

### 4.2 内盘

| 协议 | 买 | 卖 | 毕业判断 |
| --- | --- | --- | --- |
| Pons | 曲线 `buy` `0x59a87bc1`（ETH 带 value；USDG 先 approve）。开盘 5 秒读 `currentSnipeTaxBps(recipient)` | 曲线 `sell` `0xd04c6983` | `PoolGraduated` / `CurveGraduated` |
| Long | UR + DopplerHookInitializer；支付 `numeraire`（已核为股票代币） | 同左 | 无毕业（创建即 v4）；Airlock 可能有 Router 白名单窗口 |
| o1 | UR + LaunchHook；股票盘支付股票代币；16 秒内只 exact-in | 同左，收到股票代币 | 无毕业（创建即锁仓 v4） |
| Bags | `curve.buy(minOut)` + ETH | approve 后 `sell` | `BagsLens.getTokenState.migrated` |
| hood.fun | launchpad `Trade` 对应买函数（以实现 ABI 为准） | 同左 | `Graduated` 后改 v3 router |
| pools.trade | 无内盘，直接 4.1 | 直接 4.1 | 无 |

### 4.3 不要作为 v1 主路径

- 复刻样本 2 的 `0x4d819a2a` 多跳（代理可升级、路径不稳定）。
- 用 GMGN 托管 API 下单当唯一通道（链下依赖；可作对照，不能当核心）。
- 给 FCFS 排序器加 priority fee 幻想插队。

v1 最小闭环（对齐 Debot 热门）：**Pons V2 内盘 buy + Long / o1 的 UR 单跳**。pools.trade / Bags 作为 v1.1。Long 与 o1 股票盘必须先拿到 quote 代币，不能假定永远用 ETH。

## 6. 风险与未验证项

- 发射台会升级工厂（Pons V1/V2、pools.trade 双 entry）。常量要可配置。
- Airlock / 部分 Doppler 代币有「仅白名单 Router 能买」窗口（airlocks.xyz）。跟盘可能 revert，不是 RPC 问题。
- 公开 RPC 403；生产必须用 Alchemy/QuickNode 等。
- 未在浏览器走通自建买入（调研阶段不下单）。
- rh-scan 与官方 Blockscout 标签可能不一致，以官方 + 链上 log 为准。
