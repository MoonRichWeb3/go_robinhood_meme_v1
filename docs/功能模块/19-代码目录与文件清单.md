## 4. 禁止出现的路径（对照 Fourmeme，本仓库无效）

落地时若出现下列名字，视为结构偏差，必须拆回本篇清单：

```text
internal/core/parser/          ← 本链不是单 Manager
internal/handler/sell.go       ← v0 无下单
internal/trade/ 或 trader/
internal/utils/crypto.go       ← 无私钥
根目录 gofourmemev3.go 式大入口
internal/svc/servicecontext.go 里塞 ethClient+写库+解析
用 goctl 默认生成的 internal/handler、internal/logic、internal/types
把四种 ABI 写进同一个 manager.go / event_handler.go
```

`httpsvc` 若需要极薄上下文，只允许 `httpsvc/server.go` 内私有 struct 持 **只读 store**，文件不要叫 `servicecontext.go`，避免和 Fourmeme 全局大上下文混名。
