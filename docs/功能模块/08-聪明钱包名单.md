# 08 聪明钱包名单

- 最新更新时间：2026-09-02 14:40 (UTC+8)
- 适用范围：`internal/wallets`；表 `smart_wallets` 的读模型
- 来源：FR-02；底稿 §4.1–4.2；架构图 6
- 对应需求：FR-02；验收 AC-02、AC-03
- 落地包：`internal/wallets`

## 职责

以 SQLite 为唯一名单事实源；向扫块提供 **当前有效集合**（`status=active` 的小写地址）。运行中增删改 ≤1s 被感知。提供展示名给日志。

## 边界

- 不规定 CSV/API 导入；运营用 sqlite3 改表即可
- 进程 **不** 插入名单行（除评分列、`last_seen_at`、`updated_at` 由评分/扫块更新）
- 不把工厂/Router/PoolManager/LongLauncher/Airlock **默认**当聪明钱
- 新生效 **不回补** 已处理块
- 删除/拉黑 **不主动删** `wallet_events`（过期 7 天由模块 `18` 另删，与拉黑无关）

## 输入 / 输出

| | 内容 |
| --- | --- |
| 输入 | 表 `smart_wallets`；刷新周期 `RH_WALLET_RELOAD_MS`（默认 `1000`） |
| 输出 | 内存快照：`map[address]WalletView`（仅 active 用于匹配；名称查找可含非 active，避免日志用错名——**匹配仍只要 active**） |
| 副作用 | 只读名单；刷新失败不改快照 |

`WalletView`：address、display_name、primary_type、tags、level、status。

## 主路径

1. 启动：全表加载。失败则拒绝启动（没有名单也能扫新盘：允许空表启动，但不能在 SQL 错误时假装有名单）。
2. 每块处理前：若距上次成功刷新 ≥ `WALLET_RELOAD_MS`，则 `SELECT` 全表重建快照。v0 名单规模按百～千行设计，全量可接受。
3. 匹配：地址规范化后查 active 集合。创建路径：`tx.from` **或** 事件 deployer/creator 合约，**任一** 在集合即命中发盘（可写一行或两行——见模块 `09`：同一 log 只一行；若 EOA 与合约都在名单，仍 **一条** `wallet_events`，`wallet_address` 取 **tx.from**（EOA），并在日志里可附带合约命中名；若仅合约在名单、EOA 不在，则 `wallet_address` 为该合约）。
4. 运营 UPDATE/INSERT/DELETE 与扫块并发：WAL + `busy_timeout=5000`。刷新 SQL 失败：`[错误]` 类型=名单刷新失败，**沿用上一份有效快照**，下一轮再试。禁止把快照清空。
5. `last_seen_at`：仅当本块实际写入发盘/买卖事件时，由扫块写入口更新该地址。暂停后不再更新。

## 落库字段（`smart_wallets`）

底稿 §4.1 定稿。PK=`address` 小写。进程可写列：`score*`、`level`（未锁定时）、`last_seen_at`、`updated_at`。禁止进程改 `status`/`display_name`（那是运营写）。

`primary_type` 枚举：`launcher` / `winner` / `sniper` / `follower` / `kol` / `unknown`（单选）。兼类用 `tags` 逗号分隔。

`status`：`active` / `paused` / `blacklisted`。删除行 = 不再匹配（与拉黑相同效果：停新流水）。

## 日志

刷新失败必须 `[错误]`。命中日志在模块 `13`/`09`。

## 失败

| 情况 | 匹配 |
| --- | --- |
| 刷新失败 | 旧快照 |
| 地址缺 `0x` | 查询前补 `0x`；仍不是 40 hex 则不匹配 |
| 协议地址被人手动加入 active | 允许匹配（不建议）；不要在代码里静默剔除已入库名单 |

## 依赖

store 只读查询。禁止 chain/venue。

## 验收

- AC-02：加入 active 后下一笔买入有日志与记录。
- AC-03：拉黑/删除后再买，无新聪明钱日志与新行，旧行仍在。
- 改 `display_name` 后下一笔日志用新名，历史行不变。
- 从 paused 恢复：不回放旧块。

## 调研

无链上调研。名单不进配置文件。
