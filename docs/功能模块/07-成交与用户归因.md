# 07 成交与用户归因

- 最新更新时间：2026-09-02 16:05 (UTC+8)
- 适用范围：Pons 曲线 Fill（pons 包产出）+ `internal/venue/v4fill`；Transfer 归因
- 来源：FR-03、FR-05；`docs/架构/02` §3.2/§4.4；调研 `02`/`06`/`07`/`09`/`11`
- 对应需求：FR-03、FR-05
- 落地包：`internal/venue/v4fill`、`internal/domain/fill.go`

## 职责

把一笔已识别成交变成盘口无关的 `Fill`：谁是用户、meme/quote 数量、入口类型。供：展示价脏集合（全市场）与交易表（仅聪明钱）。

## 边界

- 不是第五类盘口，不产生新盘
- 未登记 pool / 未登记曲线 → 丢弃（本期股票/Long 池不会入库，其 Swap 自然丢弃）
- 全市场 Fill **不写** `wallet_events`
- 不用 `sqrtPriceX96` 当成交单价；不用中间价冒充成交
- 禁止 `Swap.sender`、Hook `Trade.executor`、Universal Router、PoolManager 当用户（除非该地址被运营显式写入有效名单，不建议）

## 领域对象 `Fill`

| 字段 | 说明 |
| --- | --- |
| Token / Category | 来自池或曲线登记 |
| Quote | 创建时记下的报价资产 |
| MemeAmountRaw / QuoteAmountRaw | 本笔用户实际得到/交出的净额，最小单位 |
| TokenDecimals / QuoteDecimals | 元数据；读失败则查 `quote_assets` / 创建行 |
| User | 实际拿到或交出 meme 的地址（小写） |
| Side | buy = 用户 meme 增加；sell = 用户 meme 减少 |
| Router | `curve` / `universal_router` / `gmgn` / `launch_and_buy` / `relay` / `unknown` |
| Block / TxIndex / LogIndex / TxHash / ChainTime | 协议事件坐标（Swap 或 CurveBuy 的 log_index，**不是** Transfer） |
| ProtocolContracts | 本笔出现过的路由/池/工厂，归因时排除 |

## 主路径 · Pons 曲线

见模块 `03`。`Router=curve`。数量用事件 quoteIn/tokensOut 或 tokensIn/quoteOut。

## 主路径 · v4 Swap（o1 / Long / Pons 毕业）

1. PoolManager `Swap`，topic0 见调研 `02`。indexed `id`=poolId，`sender` 通常是 Router，**忽略作为用户**。
2. 用 poolId 查登记；未命中 → 丢弃（可能无关 v4）。
3. 确定 meme / quote：创建行的 token vs pair/numeraire。**不要**假设 token1 是 meme。
4. 同笔 receipt 收集该 meme 的 `Transfer`（topic0 标准 ERC-20）。
5. **用户地址算法（必须实现为可单测纯函数）：**
   1. 列出本笔所有 meme Transfer 的 from/to（排除 `0x0` mint/burn 仅作辅助）。
   2. 从候选地址中去掉：PoolManager、Universal Router、Permit2、各工厂、LaunchAndBuy、LongLauncher、Airlock、两条 o1 Hook、Pons hook、GMGN 代理、以及合约目录里 `role=router|factory|pool_manager|hook|ignore`。
   3. **买**：净流入 meme 最大的剩余 EOA（或名单允许的合约）。**卖**：净流出 meme 最大的剩余地址。
   4. 多跳（GMGN）：仍取「最后一跳落到 EOA」的净额；`tx.to` 为 GMGN 代理则 `Router=gmgn`；为 Universal Router 则 `universal_router`；无法识别 `unknown`。
   5. 若去掉协议地址后找不到用户：打 `[错误]` 类型=无法归因，**不写交易表**；若数量仍能算且代币已入库，**仍可**标脏展示价（展示价不需要用户）。
6. 数量：该用户本笔 meme 净额绝对值 = `token_amount_raw`；对应 quote 净额用该用户（或其对侧池）的 quote Transfer 净额。两侧对不上超过尘埃：打 `[错误]`，Fill 数量以 meme Transfer 为准，quote 对不上则 quote 留空 → 折 U 失败。
7. `amount0/amount1` 符号只作交叉校验，成交单价 **只用 Transfer 净额比**。

### 原生 ETH quote

quote 为零地址时没有 ERC-20 Transfer。仅当 meme Transfer 已唯一归因 `User`，且该收据的 PoolManager `Swap` 总数严格等于 1，app 才调用独立 trace RPC 的 `callTracer`，按用户成功原生 value 转移净额取量：buy 必须净流出，sell 必须净流入。

trace 失败、未配置或多 Swap：只打一条中文错误；保留 meme 数量，`quote_amount_raw`、quote 单价和 U 均为 `NULL`，整块继续提交。**禁止**改用 Swap amount、`tx.value` 或 WETH Transfer。严格规则和真实样本见调研 `11`。

## 成交单价（quote 腿，尚未折 U）

```text
exec_quote_per_token = (quote_amount 人类单位) / (meme_amount 人类单位)
```

人类单位 = raw / 10^decimals。decimals 缺失则本笔不产出单价，打缺字段。禁止用 REAL 存 wei。

折 U 见模块 `11`。本模块不写美元。

## 日志

归因失败、数量对不上：`[错误]`。成功的全市场成交 **不打** `[聪明钱-*]`、**不打** `[价格]`（价格在 3 秒刷盘）。

## 失败

| 情况 | 交易表 | 展示价脏集合 |
| --- | --- | --- |
| 未登记 pool | 不写 | 不标脏 |
| 有数量无用户 | 不写 | 可标脏 |
| 有用户无 quote 数量 | 可写数量，quote/U 为 NULL | 不刷 U |
| 解 Swap 失败 | 不写 | 不标脏 |

## 依赖

contracts 目录、池/曲线登记、domain.Fill。禁止 FIFO、禁止 store。

## 验收

- 样本级：经 GMGN 多跳买入，User 为 EOA 不是代理合约，`router=gmgn`。
- Router 未进名单时不会出现在 `wallet_events.wallet_address`。
- 同一 Swap 不因 Transfer 再生成第二笔 Fill。
