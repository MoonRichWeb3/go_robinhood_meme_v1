# 05 新盘 · o1 加密

- 最新更新时间：2026-09-02 14:40 (UTC+8)
- 适用范围：`internal/venue/o1crypto`
- 来源：FR-01；底稿 §3.5；`docs/调研/07` §1.2
- 对应需求：FR-01；验收 AC-01（**本期**与 Pons 一起验收）
- 落地包：`internal/venue/o1crypto`
- **本期状态：落地。** 与股票工厂分表、分 Hook；不要实现 `o1stock`。

## 职责

只认 **加密配对工厂** `Launched`。产出 `O1CryptoLaunch`。与股票盘 **分表、分结构体、分 Hook 常量**。

## 边界

- 没有 `01` 后缀硬规则，不要从股票包 copy 校验
- quote 只识别 ETH（`0x0` 或 WETH 按调研）与 USDG；其它记 `UNKNOWN`
- 不得把加密工厂创建写入 `launch_o1_stock`

## 输入 / 输出

同股票盘形态，类型不同：工厂 `0x411f2128…0ba5`，Hook `0x441f773b…2acc`。

## 主路径 · 创建

1. 仅加密工厂 `Launched`。
2. `creator_eoa`=`tx.from`；事件 creator 进 `creator_event`。
3. hooks 必须对加密 LaunchHook；不符打 `[错误]` 仍按工厂分类入库。
4. `pair_symbol`：ETH 或 USDG，否则 UNKNOWN。
5. 登记 pool。`launch_index.category=o1_crypto`。
6. `[新盘] 盘口=o1加密`。

## 落库字段（`launch_o1_crypto`）

与股票盘同构列（无 `anomaly` 后缀规则；可无 `anomaly` 列，或恒 0）。**禁止** Go 共用一个 `o1.Launch` 类型。列清单：

`token_address`(PK)、`symbol`、`name`、`contract_uri`、`quote_address`、`quote_symbol`、`quote_decimals`、`pool_id`、`tick_spacing`、`hooks`、`supply`、`creator_eoa`、`creator_event`、`native_launch_fee_wei`、`block_number`、`tx_hash`、`log_index`、`created_at`。

无价格、无 `raw_json`。

## 买卖

同模块 `07`。禁止本包监听另一个工厂的事件。

## 验收

加密工厂创建不会出现在股票表；Hook 常量与股票 Hook 不相等。

## 调研

`docs/调研/07` §1.2。两套 Hook **不要混**。
