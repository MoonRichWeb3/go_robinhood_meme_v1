# 16 存储主键与迁移

- 最新更新时间：2026-09-02 16:05 (UTC+8)
- 适用范围：`internal/store`、`migrations/`
- 来源：需求 §2.3、§6；架构 §5；底稿 §7
- 对应需求：FR-10、AC-06、AC-07、AC-10
- 落地包：`internal/store`

## 职责

一份 SQLite：WAL、单 writer、线性迁移、自然键、地址大小写规则。按表分文件。禁止万能 Model。

## 边界

- 不解析 ABI、不算 FIFO 公式（可调用 domain）
- 不存 `raw_json` / extra_json / receipt blob
- 无意义自增代理 id 禁止
- 金额：链上最小单位 INTEGER 或 TEXT，不用 REAL 存 wei；评分 REAL 允许
- `wallet_events` 过期删除只走模块 `18` 的有界批次，禁止无 LIMIT 的全表 DELETE

## 文件与 PRAGMA

| 项 | 值 |
| --- | --- |
| 容器路径 | `/data/robinhood_meme.sqlite3` |
| 主机 | `./data` 挂卷 |
| 模式 | WAL；`busy_timeout=5000`；`foreign_keys=ON` |
| 写 | 一个连接或串行队列 |
| 读 | HTTP 只读连接 / `query_only` |
| 时间 | UTC 文本 `YYYY-MM-DDTHH:MM:SSZ` 或与之一致的 RFC3339 |

## 表与主键

| 表 | PK | 主写 |
| --- | --- | --- |
| `smart_wallets` | `address` 小写 | 运营；进程写分数/`last_seen_at` |
| `wallet_events` | 拼接 `id` | 扫块插入；**小时任务分批删过期**（模块 `18`） |
| `launch_index` | `token_address` | 扫块建行；刷价改 price_* |
| `launch_pons` / `launch_o1_stock` / `launch_o1_crypto` / `launch_long` | `token_address` | 扫块（**本期只写 pons / o1_crypto**；另两表建好留空） |
| `quote_assets` | `address` | 启动种子 + 新盘补充元数据 |
| `sync_state` | `name` | 扫块 |

GORM：四个 Launch 四个 Model，主键关自增。禁止 `map[string]any` 当主模型。

`launch_*` 与 index：同一 token 必须同行插入同一事务。分类冲突：index 已有不同 category → 整笔回滚该创建，`[错误]`。

建议 UNIQUE `(tx_hash, log_index)` 在各创建明细上防重放（可选，PK 已是 token）。

## 地址 / 哈希

写入：小写、地址带 `0x`、`pool_id` 小写 `0x`+64 hex。列 `COLLATE NOCASE`。

查询：大小写都能中。缺 `0x` **先补再比**；补完仍非法则查不到，不要模糊匹配无前缀裸 hex 与带前缀为「不同规则又不补」。

规范化纯函数可单测。

## 主键拼接

见模块 `09`。实现放 `internal/store` 或 `internal/domain/id.go`，store 必须调用同一函数。

块号超 8 位十进制：不截断，`[错误]` 类型=主键超宽。

## 迁移

`migrations/001_init.sql` 建齐上表（含 `wallet_events(chain_time)` 索引）。`002_nullable_quote_amount.sql` 在启动事务内重建 `wallet_events`，使 trace 不可用时 `quote_amount_raw` 可为 NULL，并完整重建原索引；既有非空金额原样复制。该迁移会在启动阶段短时锁表，失败由迁移事务整体回滚。

启动按文件名排序执行。禁止手工改已执行的 `001`；后续结构变更继续新增迁移。`launch_o1_stock` / `launch_long` **本期仍建表**，扫块不写。文件名见模块 `19`。

种子 `quote_assets`：ETH `0x000…000` kind=eth decimals=18；WETH；USDG kind=usdg decimals=6。股票可空着等运行补充。

## 事务

一块一个事务：本块所有 launch/event/index/登记相关写 + 最后水位。失败全滚，水位不进。刷价/评分/过期删除可用短事务，**删除必须 LIMIT 分批**，不要和跨块扫描同一无界事务。

## 备份

停写或 `VACUUM INTO`。文档即可，v0 不做自动备份任务。

## 验收

- 重启文件仍在（卷）。
- 同一 id 插入两次仍一行。
- `0xABC` 与 `0xabc` 命中；无 `0x` 的查询经补前缀命中。
- 库内无 `raw_json` 列（migration 审查）。

## 调研

无。对照 Fourmeme 禁止搬 MySQL DSN 与下单表。
