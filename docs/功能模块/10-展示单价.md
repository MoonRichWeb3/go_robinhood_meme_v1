# 10 展示单价

- 最新更新时间：2026-09-02 14:26 (UTC+8)
- 适用范围：`internal/price` 脏集合与刷盘；只改 `launch_index.price_usd`
- 来源：FR-05；底稿 §3.8；架构 ADR-6、图 7
- 对应需求：FR-05；验收 AC-05、AC-09
- 落地包：`internal/price`

## 职责

对 **已入库** 代币，用 **全市场** 最近一笔可折 U 的成交，默认每 3 秒把展示单价写入目录。给人看，不算盈亏。

## 边界

- 明细表 `launch_*` **禁止**价格列
- 无成交：保持空，不得用创建中间价 / sqrt 冒充
- 无新成交：不写库
- 喂价缺失：本次不刷，保留上次或空，**禁止写 0**
- 未入库 pool 的 Swap 不进入脏集合
- 不要每笔成交打 `[价格]`

## 输入 / 输出

| | 内容 |
| --- | --- |
| 输入 | 任意 `Fill`（不限聪明钱）+ 模块 `11` 的成交单价 U |
| 内存 | `token → {priceU, block, tx, at}` + 脏标记 |
| 输出 | 定时批量 `UPDATE launch_index SET price_usd, price_block, price_tx, price_at` |
| 配置 | `RH_PRICE_FLUSH_SEC` 默认 `3` |

## 主路径

1. Fill 算出 `exec_usd_per_token` 非空，且 token ∈ `launch_index` → 覆盖内存最新价，标脏。
2. Fill 无 U → 不标脏（也不把价改成 0）。
3. 定时器（可与扫块同进程切面，必须走 **同一写入口**）：取出脏集合。
4. 每个脏 token：若价相对表内未变可跳过 UPDATE；否则 UPDATE 并打一行 `[价格]`。
5. 清空已刷脏标记。窗口内多笔只留最后一笔。
6. 脏集合有界：默认最多 `5000` 个 token；超出淘汰最旧脏项并 `[错误]` 类型=脏集合溢出（下次成交可再进）。禁止无界 map。

重启：内存空，表保留上次 U；要等新成交才再变。

刷价协程禁止第二 SQLite 写连接狂写；排队到扫块 writer。

## 落库

仅 `launch_index`：`price_usd`（人类小数，REAL 可）、`price_block`、`price_tx`、`price_at`（UTC）。从未成交保持 NULL。

## 日志

```text
[价格] 时间=… 类型=价格 盘口=… 代币=… 配对=… 单价U=… 来源=最近成交 交易=… 块高=…
```

来源展示名固定 `最近成交`。禁止 `spot_quote=` 英文键。

## 失败

UPDATE 失败：脏标记保留，下轮再试，`[错误]`。部分成功允许（已刷的去掉脏）。

## 依赖

price、store writer、index 读盘口名。禁止 FIFO。

## 验收

- AC-05：非聪明钱成交约 3s 内目录 U 变为该笔；无成交币仍空。
- 3s 窗口两笔成交：表上是后一笔。
- 缺价：不出现 `单价U=0`。

## 调研

数量→成交价算法在 `02`/`06`/`07`/`09`；本模块只规定节奏与写哪一列。
