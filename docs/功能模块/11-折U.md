# 11 折 U

- 最新更新时间：2026-09-02 16:05 (UTC+8)
- 适用范围：`internal/price` 喂价端口；成交单价 U 与 1 单位 quote 的 USD
- 来源：需求 §7；FR-04～FR-06；`docs/调研/10-币安ETH美元喂价.md`；`docs/调研/11-v4原生ETH成交净额.md`
- 对应需求：§7；验收 AC-09
- 落地包：`internal/price`（含独立币安 HTTP 循环，**不**放在 chain 包）

## 职责

`成交单价U = exec_quote_per_token × (1 单位报价资产的美元)`。没有可靠喂价则返回空错误，**禁止返回 0 当成功价**。

ETH：内存读取币安 `ETHUSDT` 缓存。USDG：按 1。股票：本期缺价（o1 股票 / Long 暂缓）。

原生 ETH 的 `quote_amount_raw` 必须先通过模块 `07` 的单 Swap callTracer 净额门槛取得。trace 不可用时该字段为 `NULL`，本模块不执行折 U；不得用 Swap delta、交易 value 或 WETH Transfer 补值。

## 边界

- 不读 Debot/GMGN 网页价当事实
- 不把展示延迟价喂回交易行
- USDG 脱锚策略未定：v0 **按 1.0 USD**
- **禁止**在扫块循环里同步 `http.Get` 币安
- **禁止**为行情配置币安 API Key
- 股票 quote：本期无源，`ErrNoFeed`，禁止写 0。恢复 o1 股票 / Long 时再加喂价，**本期实现不要写 `TODO(feed)`**。

## 输入 / 输出

```text
QuoteUSD(quote_address) -> (usd_per_1_quote, err)
ExecUSD(exec_quote_per_token, quote_address) -> (exec_usd_per_token, err)
```

`err=ErrNoFeed`：调用方把 U 置 NULL，打 `[错误] 缺价=是`，不刷展示 U，不进 FIFO/评分。

禁止：`usd=0` 且 `err=nil`。实现上 0 视为非法，按缺价处理。

## 规则表

| quote | 本期 | 未就绪行为 |
| --- | --- | --- |
| USDG `0x5fc5360d…d168` | `1` | 无 |
| ETH `0x0` / WETH | 乘内存中的 ETHUSDT（当 1 USD） | 缓存失效且拉不到 → 缺价 |
| 股票代币（`quote_assets.kind=stock`） | 无源 | 缺价 |
| 未知 | — | 缺价 |

`quote_assets` 必须能回答 kind 与 decimals。启动种子：ETH、WETH、USDG。股票行本期可不补。

## ETH：独立 HTTP（落地口径）

调研事实与 URL 只引用 `docs/调研/10`，此处定进程行为。

| 项 | 默认 |
| --- | --- |
| 协程 | 启动后独立循环；失败不影响扫块存活 |
| URL | `{RH_BINANCE_BASE_URL}/api/v3/ticker/price?symbol={RH_BINANCE_ETH_SYMBOL}` |
| 默认 base | `https://api.binance.com` |
| 默认 symbol | `ETHUSDT` |
| 间隔 | `RH_ETHUSD_POLL_SEC` 默认 `10` |
| HTTP 超时 | `RH_BINANCE_TIMEOUT_MS` 默认 `3000` |
| 缓存新鲜 | `RH_ETHUSD_TTL_SEC` 默认 `30` |
| 降级旧值 | 拉取失败时，若上次成功距今 ≤ `RH_ETHUSD_STALE_SEC`（默认 `300`）仍可用旧值，同时 `[错误]` 类型=喂价降级；超过则 `ErrNoFeed` |

主路径：

1. GET，解析 `price` 字符串为正数。
2. 写入内存 `{usd_per_eth, fetched_at}`。
3. 折 U 只读内存：`fetched_at` 在 TTL 内 → 用新值；否则先不阻塞等待，用降级规则。
4. HTTP 429：指数退避（建议 1s→上限 60s），打 `[错误]`，扫块继续。
5. `price` 非法或非 200：当失败，不清成 0。

## 主路径（一笔成交）

1. 已知 `exec_quote_per_token`（模块 `07`）。
2. 查 quote kind。
3. 取 `usd_per_1_quote`。
4. 相乘得 U。写入前不要 NaN/Inf。
5. 快照可写入 `wallet_events.quote_usd`，与 `exec_usd_per_token` 同时空或同时有。

## 日志

缺价：`[错误] 类型=错误 缺价=是 报价= 代币=`。币安失败：`[错误] 类型=喂价失败`（不要打印完整 URL 密钥；本接口无密钥）。

## 失败

超时、429、解析失败：见上表降级。禁止用 `0` 填 U。

## 依赖

quote_assets、config、独立 `http.Client`。禁止 venue 内写死 `* 0`。禁止 import chain RPC 客户端去拉币安。

## 验收

- USDG 盘：U 可算。
- ETH 盘：币安缓存有效时 `exec_usd_per_token` 非空且非 0。
- 币安不可达且超过 stale 窗：事件可入库，U 为 NULL，日志缺价，目录不刷 0。
- 单测：端口返回 error 时 store 层拒绝写 `0`；喂价 goroutine 可用 fake HTTP。
