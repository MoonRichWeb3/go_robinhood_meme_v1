## 职责

只认 **股票配对工厂** `Launched`。产出 `O1StockLaunch`。买卖不在本包扫全链 Swap，只消费共享 v4 Fill。

## 边界

- 禁止复用 `O1CryptoLaunch` / 加密 Hook 常量
- 禁止用 Debot「股票盘」标签分类
- 后缀不是 `01`：**仍入库**，`anomaly=1`，打 `[错误]`，不得拒绝
- Hook 填错：仍按 **工厂** 分类入库，打 `[错误]` 类型=Hook不符

## 输入 / 输出

创建：工厂 `Launched` + 同笔 `Initialize`。输出领域对象 + 登记 `pool_id`。

## 主路径 · 创建

1. address = 股票工厂 `0xe64ac411…f297`，topic0 = `Launched`。
2. 解码：token、poolId、creator（事件）、quote、supply、tickSpacing。
3. `creator_eoa` = `tx.from`；`creator_event` / index 的 `creator_contract` = 事件 creator（常为 Token Deployer）。
4. 校验 token 地址后缀 `01`（小写 hex 最后两位）。不符：`anomaly=1`。
5. 校验 hooks = 股票 LaunchHook `0x778b0c4e…eacc`（来自同笔 Initialize 或 PoolKey）。不符打错误，分类仍 `o1_stock`。
6. `quote_symbol`：查 `quote_assets` / 股票 catalog；缺失 `UNKNOWN`。
7. `native_launch_fee_wei` = `msg.value`。
8. 登记 pool。`launch_index.category=o1_stock`，`price_usd` 空。
9. `[新盘] 盘口=o1股票`。

幂等与分类冲突同模块 `03`。
