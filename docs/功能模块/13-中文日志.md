# 13 中文日志

- 最新更新时间：2026-09-03 10:55 (UTC+8)
- 适用范围：`internal/logx`；所有面向人的 stdout，以及 Docker 下可选磁盘文件
- 来源：FR-09；底稿 §5.2；需求 §9 示例；`docker-compose.yml` 的 `./logs:/logs`
- 对应需求：FR-09
- 落地包：`internal/logx`

## 职责

标准输出：中文标签 + 中文键名 + `键=值`。库表/JSON API 仍英文。禁止业务里 `fmt.Println`。

`RH_LOG_DIR` 为空时只写 stdout。Docker Compose 设为 `/logs`，并挂载项目根目录 `logs/`，文件名为 `robinhood-meme.log`；同时仍写 stdout，`docker compose logs` 可用。

## 边界

- 不把列名改成中文
- debug 级可英文，但默认面向人的级别必须中文键
- 禁止 stdout 出现 `kind=`、`spot_quote=`、`exec_usd=` 这种英文键

## 行格式

```text
[标签] 时间=2026-09-01T08:01:08Z 类型=… 盘口=… …
```

值含空格用双引号。时间为 UTC。处理时间键名 `时间`；链上块时间键名 `链上时间`。

## 标签与类型

| 标签 | 类型（日志键） | 何时 | 禁止 |
| --- | --- | --- | --- |
| `[新盘]` | 发盘 | 四类创建入库成功 | 解析失败当新盘 |
| `[聪明钱-发盘]` | 发盘 | 有效名单命中创建 | 协议合约误匹配（除非运营放进名单） |
| `[聪明钱-买入]` | 买入 | 有效名单买 | 无数量 |
| `[聪明钱-卖出]` | 卖出 | 有效名单卖 | 无数量 |
| `[价格]` | 价格 | 3s 刷入 index，每币一行 | 每笔 Swap 打一次 |
| `[错误]` | 错误 | 解析失败、缺价、分类冲突、超仓、重组、RPC、名单刷新失败 | 静默丢弃已知 topic |
| `[信号]` | 信号 | FR-07 现算命中 | 落 `project_signals` 表 |
| `[清理]` | 清理 | 交易表过期分批删除结束（模块 `18`） | 每批不打 |

盘口展示名：`Pons` / `o1股票` / `o1加密` / `Long`。库内仍是 `pons` 等。

价格来源展示：`最近成交`。

## 买卖必填键

`时间`、`链上时间`、`类型`、`盘口`、`代币`、`钱包`、`钱包名`（有则）、`方向`、`配对`（有则）、`数量`、`成交单价U`、`交易`、`块高`。

卖出能 FIFO 时加 `已实现盈亏U`。

U 缺失：`成交单价U` 可为空字符串，并 `缺价=是`（可在同一行或紧跟 `[错误]`）。不得写 `成交单价U=0` 表示未知。

## `[新盘]` 必填键

`时间`、`盘口`、`代币`、`配对`、`创建人`、`名称`（可空）、`交易`、`块高`、`链上时间`。

## `[价格]` 必填键

`时间`、`类型=价格`、`盘口`、`代币`、`配对`、`单价U`、`来源=最近成交`、`交易`、`块高`。

## `[错误]` 必填键

`时间`、`类型=错误`，以及能定位的 `块高`/`交易`/`代币`。缺价加 `缺价=是`。

## 实现约束

- 统一 `logx.Info(tag, fields map)`，字段 key 为中文。
- `LOG_LEVEL`：默认 info。错误始终输出。
- `RH_LOG_DIR`：可选绝对路径；空则不写文件。Docker 为 `/logs`。本期不滚动切割，文件会持续增长。
- HTTP 访问日志若有：不要盖过扫块中文行；可独立级别。

## 验收

对照需求 §9 三行示例：键名中文，盘口中文。单测：禁止英文键出现在渲染结果里（可维护英文键黑名单）。
